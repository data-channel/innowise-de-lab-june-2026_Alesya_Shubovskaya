Описание предметной области «Магазин продуктов»

Предметная область описывает процесс розничных продаж в сети продуктовых магазинов.
Основная операция — это продажа товара, которая фиксируется в момент покупки.
В процессе продаж участвуют следующие основные сущности: Sales, Products, Customers, Employees, Shops, Categories, Cities, Countries.
Продажи фиксируются по каждому чеку, включая количество товаров, цену и применённые скидки.
Товары имеют уникальный идентификатор, название, цену за единицу и относятся к категориям.
Каждый сотрудник работает в конкретном магазине.
У каждого магазина есть адрес и город, а город привязан к стране.
Клиенты также привязаны к городам через свои адреса.
Фиксируемые операции: создание продажи, изменение данных о товарах, приём на работу сотрудников, открытие новых магазинов.
Ключевые атрибуты сущности Products: product_id, product_name, price, category_id.
Ключевые атрибуты сущности Employees: employee_id, first_name, last_name, birth_date, hire_date.
Эти данные позволяют анализировать выручку, эффективность магазинов и сезонные колебания спроса.
