Данная предметная область описывает процесс розничных продаж в сети продуктовых магазинов. 
Основной операцией является факт покупки, который фиксируется в момент продажи товара. 
В процессе участвуют следующие ключевые сущности: продажи, товары, клиенты, сотрудники, магазины, локации и категории товаров.
Продажи фиксируются по каждому чеку, включая количество товаров, цену и применённые скидки. 
Товары имеют уникальные идентификаторы, названия, цену за единицу и относятся к определённым категориям. 
Каждый сотрудник работает в конкретном магазине, а у каждого магазина есть свой адрес и город.
Для товаров ключевыми атрибутами являются: уникальный идентификатор, название, цена и категория. 
Для сотрудников — идентификатор, полное имя, дата рождения и дата найма. 
Система позволяет анализировать выручку, сравнивать эффективность магазинов и выявлять сезонные колебания спроса на категории товаров.
Такая модель данных лежит в основе построения DWH и дальнейшей BI-аналитики для поддержки управленческих решений.
